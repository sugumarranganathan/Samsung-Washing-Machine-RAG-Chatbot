# 🧺 Samsung Washing Machine Technical Support AI Chatbot

A serverless RAG-based technical support chatbot using Qdrant, Groq LLM, FastAPI, Docker, AWS Lambda, API Gateway, CI/CD, DevOps, and MLOps practices.

## Architecture

User → API Gateway → AWS Lambda → FastAPI → RAG → Qdrant + Groq → Answer

## Technologies

- Python
- RAG
- Qdrant
- Groq LLM
- FastAPI
- Docker
- AWS Lambda
- API Gateway
- Amazon ECR
- GitHub Actions
- CI/CD
- AWS CLI
- DevOps
- MLOps

## Features

- Samsung washing-machine technical support
- Semantic document retrieval
- Error-code troubleshooting
- Maintenance guidance
- RAG-based answers
- Serverless AWS deployment
- Docker containerization
- Automated CI/CD deployment

## Example

Question:

What does error 4C mean?

Answer:

Error 4C indicates a water-supply problem. Check that the water supply is turned on, the inlet hose is connected correctly, and the hose is not kinked.
